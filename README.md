# SecureCheck

A comprehensive password security analysis and generation tool designed to help users assess password strength and generate secure passwords with customizable criteria.

# Overview

SecureCheck is a full-stack password security application that provides real-time password strength analysis and intelligent password generation. Whether you're creating new credentials or evaluating existing ones, SecureCheck helps ensure your passwords meet modern security standards.

# Features

- Password Strength Analysis: Evaluate password security based on industry-standard criteria including length, character diversity, and complexity
- Password Generation: Create strong, randomized passwords with customizable parameters
- Password History Tracking: Maintain a secure history of analyzed passwords with optional labels for easy reference
- Duplicate Detection: Identify when passwords have been previously analyzed to prevent reuse
- User-Friendly Interface: Intuitive web-based interface for seamless interaction
- REST API: Programmatic access to all core functionality via well-designed API endpoints

# Technology Stack

- Backend: Node.js with Express.js framework
- Database: SQLite (better-sqlite3) for efficient local storage
- Frontend: Vanilla JavaScript with static asset serving
- API Features: CORS-enabled for cross-origin requests
